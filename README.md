**[K-Lite Codec Pack Basic](https://codecguide.com/download_k-lite_codec_pack_basic.htm)** is a lightweight yet powerful collection of all the essential codecs needed for multimedia playback. It supports a wide variety of audio and video formats while keeping the system footprint as small as possible.

---

### ✨ Key Features
* **Universal Compatibility:** Enables playback for almost any multimedia file format in your favorite media player.
* **Essential Codecs Only:** Focuses strictly on playback essentials without any bundled players.
* **Lightweight:** Extremely low system resource consumption and very small installer size.

---

### 💻 Quick Installation via Chocolatey

You can install this package with a single command. Open your Command Prompt (`cmd`) or `PowerShell` as Administrator and run:

```powershell
choco install k-litecodecpackbasic
```
